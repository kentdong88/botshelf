# 新版实现与验证边界

新版默认进入 Amazon shelf lab，旧版 WANDS research lab 保留。

已完成：六个真实 ESCI 货架、每货架八个同查询商品、五维透明审计、所有商品完整排序、选中率/前三率/平均排名、真实源查询买家场景、结构化 Codex 接口和并发、证据锁定改写、人工批准、商家带出处补全、三阶段配对对照、持久化与结果导出。

实际分析使用 40,000 条去重美国站查询—商品对；覆盖率分箱的 Exact 比例为 43.19%、56.38%、65.59%、88.13%。不是参考方案里的 37% 和 84%。逻辑回归采用查询不交叉的留出集；结论仅为相关性，不是因果。

默认离线模式公开 BM25、规格出现次数、属性出现次数和固定噪声公式。它能验证链路，但不能证明真实 AI 偏好。关键词计数和原文重复会机械影响规则分数，页面和文档明确披露这一点。

改写优先保留完整源事实而非自由生成句子；缺少事实不会为凑足五条要点而编造。补全必须由用户填写，附实际来源及确认人。模型只看到标为商家确认的值，看不到确认人的身份和内部来源备注。

API 密钥、SQLite、虚拟环境和原始大数据文件不进入 GitHub。复现脚本、精简货架、特征表、许可证和测试可以进入仓库。Codex 使用本机 CLI 和现有登录；CODEX_MODEL 固定模型。完整真实模型评估仍待冻结测试集后运行。
