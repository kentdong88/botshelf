# 实施说明

已实现四个 Streamlit 工作区、200 件真实 WANDS 餐桌、40 条事实驱动的草拟需求、证据化修订、
单案例人工审核、A/B 配对评估、SQLite 历史和 JSON/CSV/HTML 导出。模型调用可配置，失败最多重试一次。

为保证诚实与可运行性，采用以下明确边界：

- 当前没有模型 API 密钥，实际交付结果为离线规则基线；真实模型实验尚未执行。
- 自由文本用于检索；硬条件由表单确认，不假装实现通用自然语言约束解析。
- 尺寸缺少单位时保持未知。多数预设实验使用桌面材质、形状和座位数。
- 需求是基于源事实生成的草稿，人审标记全部初始为 false；正式评估需要逐条需求和修订审批。
- 实验 B 对所有候选隐藏标题/描述，再移除目标商品的一个属性；检索固定使用原始目录。
- 原始测试集里存在 20 个未召回目标；保留该结果，不调整样本制造提升。
- 单次对照只改变商家批准的字段。批量探索实验使用全部可支持的建议，并标记尚未人审。
- 商家访谈、计时研究和比赛录屏需要真实参与者或操作记录，未生成虚构证明。

后续团队操作：配置密钥与模型 → 单次 live 冒烟测试 → 审核需求和修订 → 冻结测试集运行 →
将 live 结果补充到英文简介 → 录制完整演示。
